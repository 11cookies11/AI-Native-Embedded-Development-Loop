# Resume Section

## AI-Native Embedded Development Loop

Role: Project initiator / architecture designer / core developer

Built an AI-agent-driven embedded software and hardware development loop covering agent orchestration, embedded software simulation, real hardware debugging, hardware design automation, protocol testing, and developer tooling.

Core projects:

- [SOAA](https://github.com/11cookies11/Stack-Orchestrated-Agent-Architecture): stack-based agent orchestration architecture
- [EmbeddedLoop](https://github.com/11cookies11/EmbeddedLoopDemo): Renode-based embedded software simulation and validation loop
- [NexDAP](https://github.com/11cookies11/NexDAP): agent-controllable CMSIS-DAP debug probe based on RP2040 + ESP32-C3
- [KiCad Agent Suite](https://github.com/11cookies11/kicad-agent-suite): AI-assisted hardware design automation based on `circuit-model.json`
- [ProtoFlow](https://github.com/11cookies11/ProtoFlow): YAML DSL + state-machine runtime for embedded protocol testing

Supporting tools:

- [RenodeWorkbench](https://github.com/11cookies11/RenodeWorkbench): VS Code Renode session manager
- [ShellLink](https://github.com/11cookies11/ShellLink): ESP32-C3 device-side shell and DSL runtime
- [Where](https://github.com/11cookies11/Where): VS Code agent task visualization plugin
- [StencilForge](https://github.com/11cookies11/StencilForge): Gerber / Excellon to 3D-printable stencil STL tool

Technical highlights:

- Designed stack-based task orchestration for AI-agent workflows.
- Built Renode-based multi-MCU embedded validation scenarios.
- Designed a real-hardware debug loop using RP2040 + ESP32-C3 CMSIS-DAP.
- Modeled hardware design as structured intermediate representation.
- Built protocol workflow runtime for UART / TCP / Modbus / XMODEM testing.
